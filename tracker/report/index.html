5. Method and limits

  • None of these is the consumer app. Each engine is an official API, a vendor's coding-agent CLI, or (for Google) a search-data provider, with web search on and the location set to Austin, Texas, US. A real patient in the ChatGPT, Claude, Perplexity or Gemini app may see something different: the apps add their own system prompts, use device location and may use history or memory. Treat these numbers as a clean, non-personalised proxy, and compare with answers pasted from the apps (vistrack import).
  • What each engine is.
    • OpenAI model via Codex CLI: An OpenAI model with its native web search, run through OpenAI's Codex coding-agent CLI under a ChatGPT Plus login (read-only sandbox, empty working directory). It is not the ChatGPT app and not the API. Location is only the sentence "I'm in Austin, Texas." added to the prompt. Codex is a coding agent, so its style and search behaviour may differ from ChatGPT.
    • Claude Haiku via Claude Code CLI: Claude Haiku with Claude's WebSearch and WebFetch tools, run through the Claude Code CLI under a Claude subscription, with the user's memory files, settings and plugins switched off and a minimal system prompt. It is not claude.ai and not the API. Location is only the sentence "I'm in Austin, Texas." added to the prompt.
  • Models used. OpenAI model via Codex CLI: gpt-6-luna; Claude Haiku via Claude Code CLI: haiku. Each run stores model, tool version, timestamp, location, the raw JSON response and its SHA-256.
  • Gemini is not measured. Its grounding terms prohibit storing and analysing results.
  • Errors are not "not mentioned". Failed or rate-limited calls are retried, then stored as errors and left out of every rate. Errors in this batch: codex_cli 0/50, claude_cli 0/30.
  • Mention = the practice is named (alias match on normalised text), including negative mentions, which are flagged separately. Cited = a cited URL belongs to the practice's domain.
  • Intervals. 95% Wilson per cell. Each rate pools 10 prompts × the engine's repetitions (OpenAI model via Codex CLI: 50 answers; Claude Haiku via Claude Code CLI: 30 answers); overlapping intervals mean the difference is not established. Per-prompt cells (section 4) have only 3–5 runs and very wide intervals. The by-prompt interval is a percentile bootstrap over 10 prompts, centred on the mean of per-prompt rates; it undercovers with so few prompts, so use it as a warning, not a bound.
  • No causal claims. This is a snapshot; it says nothing about why a practice is or is not named.

Extractor validation

On real answers: 40 answers from this batch, labelled by a model (Claude) that read each one in full, before seeing any extractor output; 9 of them name a tracked practice (12 true mentions in total). The labels are not yet spot-checked by a human. Precision / recall on mentions:

What happened: The first validation on the 40 real labelled answers gave regex precision 100% and recall 83% (10 of 12 true mentions): engines write "Dr. H at Practice H Cosmetic Dentistry", which the full practice name never matched. An alias for the doctor's name was then added and the same sample re-measured (100% / 100%), so that figure is tuned on the sample and will overstate accuracy on new answers. The LLM judge (Claude Haiku via the Claude Code CLI) found all 12 from the start. Both the labels and the judge come from Claude models, so their errors may be correlated.

With only 12 true mentions in the sample, these percentages are rough: one error moves them by several points. The judge was run on 40 of the 40 labelled answers.
